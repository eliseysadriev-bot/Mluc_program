# Mluc

**Mluc (My Lightweight Unusual Console)** is a small project that I'm developing entirely on my own.

There isn't much in it yet, but there are already a few things to try!

## Features

Mluc currently has two commands:

- **`a`** — Displays a list of available commands.
- **`b`** — A work-in-progress command. It can currently display a byte from memory in hexadecimal format, but I plan to expand it for low-level system control.

## Technical Details

- Written in **NASM Assembly**.
- Runs in **16-bit real mode**.
- Uses **BIOS interrupts** for keyboard input and screen output.
- Can be tested using **QEMU**.

## Development

Mluc is still in its early stages.

I'm building it step by step, learning more about Assembly, memory, and low-level programming along the way.

More features and improvements are planned for future versions.

## A Small Note

This is a personal learning project, and I'm writing the code myself.

It may be simple right now, but I hope to make it more interesting over time.
